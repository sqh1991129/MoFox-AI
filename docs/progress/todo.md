# TODO

本文档用来记录当前项目后续比较值得处理的事项。

## 短剧垂直功能

总体思路：不另做独立 pipeline 页面，把短剧做成画布上的垂直模板——Agent 一键把剧本展开成分镜/镜头节点，逐镜人工干预，最后通过合成节点导出成片。按 A → D 递进实现。

### A. 短剧项目模板（纯前端，优先）

- 新增"短剧项目"画布入口模板：剧本 → 分镜 → 角色卡 → 逐镜视频 → 配音的节点布局骨架
- 复用 Agent 的 script / image-storyboard / image-character-sheet / video-multi-shot / audio 技能，一键把剧本拆镜头并展开为画布节点
- 现有能力基本够用，只做模板化和流程串联，不改后端

### B. 服务端合成导出

- 后端新增 FFmpeg 合成任务：按镜头顺序拼接视频 + 配音混音 + 字幕（SRT）烧录 + BGM，输出整集成片
- 画布新增"合成节点"：引用上游视频/音频/文本节点，配置镜头顺序、音轨和字幕后提交任务
- 合成任务接入现有任务持久化链路（刷新恢复、停止、失败重试、终态清理）
- 成片 media 走现有 S3/R2 存储和下载链路

### C. 轻量剪辑时间轴

- 对真实视频节点提供镜头序列/剪辑时间轴：排序、时长、出入点、转场的轻量编辑
- UI 形态参考导演台时间轴（轨道、拖拽、播放预览），但作用对象是画布媒体节点
- 时间轴编辑结果作为合成节点的参数来源，提交后端 FFmpeg 任务

### D. 剧集与角色一致性增强

- 剧集结构化：剧 → 集 → 镜头的组织方式（一集一画布或画布内元数据分组，实现时二选一）
- 角色一致性：角色锚点图自动注入该角色出现的每个镜头参考图，减少手工连线
- 跨集角色卡/场景卡沉淀到"我的素材"或提示词库，支持复用

### 注意事项

- 火宝短剧（huobao-drama）为 CC BY-NC-SA 4.0 非商用协议，只参考其产品流程和模型选型，不搬运其代码和素材
- 视频模型沿用现有渠道（Seedance、可灵、MiniMax 等），不为此新增私有依赖

## 商业化与会员体系 (SaaS)

总体思路：复用现有底层完善的算力点数（Credits）扣除、退款与审计流水，补齐上层的商业会员等级、权益管控、在线支付与前端套餐选购闭环。

### A. 会员等级与权益模型 (Membership Plans)

- [ ] 用户模型扩展：增加 `planLevel`（free/basic/pro/ultra）、`planExpireAt`（到期时间）、`monthlyCredits`（套餐月额度）字段
- [ ] 权益拦截与配额控制：按套餐等级限制并发生成任务数、区分高级模型（如可灵 3.0、Seedance 2.0、2K 画质）的使用权限
- [ ] 会员状态巡检：支持定时任务（Cron）检查会员到期状态并自动降级为 free

### B. 在线支付与充值闭环 (Payment & Recharge)

- [ ] 订单模型设计：新增 `Order` 数据表，记录用户充值与套餐购买订单、交易状态、支付渠道、第三方交易单号
- [ ] 支付通道接入：支持微信支付、支付宝或第三方聚合支付（如易支付/Stripe），提供统一下单与异步 Webhook 回调处理
- [ ] 算力包与自动充值：支付成功后自动充值算力点数（`Credits`）并写入现有 `CreditLog` 审计流水中

### C. 商业化前端界面 (Pricing & Billing UI)

- [ ] 套餐定价中心弹窗/页面：展示标准版、进阶版、豪华版等多档位对比卡片与权益清单
- [ ] 收银台与扫码支付：支持直接弹出微信/支付宝二维码并轮询/推送支付成功状态
- [ ] 个人中心会员徽章：顶部导航栏与个人中心展示当前会员等级徽章（PRO/VIP）及算力余量
